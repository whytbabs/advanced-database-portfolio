Project Title

CampusCart – E-commerce Management System

1. Introduction

This project is developed as part of the Advanced Database Systems course. It demonstrates practical knowledge of database design, query processing, transaction management, NoSQL databases, and distributed and cloud database systems.

2. Selected Case Study

Organisation: CampusCart E-commerce Management System.

CampusCart is a simulated online shopping platform that allows customers to browse products, place orders, make payments and track deliveries.

The system also supports administrators, inventory officers and sales personnel in managing business operations.
